# What's new in LGA Mighty Tools

## v1.31 (2026-10-04)

- **Improved:** The app waits to offer or install an update while Disk Space is deleting files.

## v1.30

- **New:** LGA Mighty Tools is now available for macOS, on Apple Silicon and Intel, with its five tools: Open in NukeX, Nuke Shortcuts, Disk Space, Folder Switch and Link Redirector. (macOS only)
- **New:** The app checks for new versions and installs them for you in one click. (macOS only)
- **Fixed:** Updating from inside the app works now: earlier versions stop with an integrity error, so install this one once with the installer from the download page. (Windows only)

## v1.27

- **Improved:** The app checks for a new version every few hours while it stays open, not only at startup, and Later postpones the notice for a day.
